Here’s a specific breakdown of the concepts and modules used in your point_history_classification.ipynb script, with direct reference to what is actually used:

Supervised Learning
	Type: Multi-class classification
	Task: Classify dynamic hand gestures based on the movement history of a hand point (typically the fingertip) over time
	Labels: Integer class labels (e.g., 0, 1, 2, 3) from the first column of the CSV
Neural Network Model
	Framework: TensorFlow Keras
	Model Type:
		Feedforward neural network (MLP) by default
		LSTM-based model if use_lstm = True
	Architecture (MLP):
		Input layer: 32 features (16 time steps × 2 coordinates)
		Dropout (0.2)
		Dense (24 units, ReLU)
		Dropout (0.5)
		Dense (10 units, ReLU)
		Output Dense (NUM_CLASSES units, softmax)
	Architecture (LSTM, if enabled):
		Input layer: 32 features reshaped to (16, 2)
		Dropout (0.2)
		LSTM (16 units)
		Dropout (0.5)
		Dense (10 units, ReLU)
		Output Dense (NUM_CLASSES units, softmax)
Data Handling
	Data Source: CSV file (point_history.csv)
	Features: Columns 1–32 (16 time steps × 2 coordinates)
	Labels: Column 0 (gesture class)
	Splitting: train_test_split from scikit-learn (75% train, 25% test, random seed 42)
Model Training
	Loss Function: sparse_categorical_crossentropy (for integer labels)
	Optimizer: Adam
	Metrics: Accuracy
	Callbacks: ModelCheckpoint (save best model), EarlyStopping (patience=20)
Model Evaluation
	Test Set Evaluation: model.evaluate
	Confusion Matrix: sklearn.metrics.confusion_matrix
	Classification Report: sklearn.metrics.classification_report
	Visualization: matplotlib and seaborn for plotting confusion matrix
Model Export
	Save Format: HDF5 (.hdf5) for Keras, TFLite (.tflite) for deployment
	Quantization: TFLite model is quantized for efficiency
Inference
	Keras Model: model.predict
	TFLite Model: tf.lite.Interpreter for running inference on the quantized model
	Python Modules Used
	numpy: Array operations and data loading
	tensorflow: Model building, training, saving, and TFLite conversion
	sklearn.model_selection: train_test_split
	sklearn.metrics: confusion_matrix, classification_report
	matplotlib, seaborn: Visualization of confusion matrix
	pandas: DataFrame for confusion matrix display
